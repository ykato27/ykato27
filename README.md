# My Profile

Data Scientist / 機械学習エンジニア。データ分析、機械学習モデルの構築、Streamlit等でのアプリ化を中心に活動しています。

## 主なリポジトリ

- [keiba-solo-db](https://github.com/ykato27/keiba-solo-db) — 競馬データ分析システム（JRAデータの収集・SQLite蓄積・Streamlit可視化・勝馬予測）
- [property-price-lookup](https://github.com/ykato27/property-price-lookup) — 機械学習で割安な中古マンションを探すシステム
- [talent-graph-analyzer](https://github.com/ykato27/talent-graph-analyzer) — GNNを用いた優秀人材の特徴抽出・分析システム
- [SDP-Analysis-Dashboard-Unified](https://github.com/ykato27/SDP-Analysis-Dashboard-Unified) — 製造業向けSDP（Skill Driven Production）分析ダッシュボード統合版
- [whisper-transcribe-app](https://github.com/ykato27/whisper-transcribe-app) — Whisperを使った音声文字起こしアプリ
- [video-memory-maker](https://github.com/ykato27/video-memory-maker) — 子供の顔が映るシーンを自動抽出するハイライト動画作成ツール
